# No Cookies Blocklist for AdGuard

Deze lijst blokkeert domeinen die gebruikt worden door "No Cookies" voor tracking, advertenties en externe content.

## Hoe te gebruiken in AdGuard
1. Open AdGuard > Filters.
2. Klik op "Aangepaste filters".
3. Voeg de volgende URL toe: https://raw.githubusercontent.com/hack2881/no-cookies-blocklist/refs/heads/no-cookies.txt/no-cookies.txt
